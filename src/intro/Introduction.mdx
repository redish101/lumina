<Subtitle>个人使用的 React 组件库</Subtitle>

基于 **React + TypeScript** 的组件库，使用 **CSS Modules** 编写样式，通过 **Storybook** 编写文档。源码不打包，交给使用方（Next.js）编译。

## 技术栈

| 模块   | 方案                                                      |
| ------ | --------------------------------------------------------- |
| 分发   | 直接发布源码，无构建产物（`exports` 指向 `src/index.ts`） |
| 编译   | 使用方负责：Next.js（App Router）转译 TSX 与 CSS Modules  |
| 样式   | CSS Modules + 设计令牌（CSS 变量）                        |
| 类型   | TypeScript（严格模式），类型随源码一起提供                |
| 文档   | Storybook（`@storybook/addon-docs` 自动生成 Docs 页）     |
| 包管理 | pnpm                                                      |

## 组件

| 分类 | 组件                                                                           |
| ---- | ------------------------------------------------------------------------------ |
| 表单 | Button、Input、Checkbox、Switch、SegmentedControl、SegmentedTabs、ShortcutKeys |
| 展示 | Pill、Tag、StateDot、TextShimmer、AnimatedRows                                 |
| 浮层 | Menu、Tooltip、Toast                                                           |
| 媒体 | ImagePreview、ImageLightbox、DraggableImage                                    |

每个组件的 Docs 页顶部有行为说明，下面是 props 表格（含中文说明与默认值）；story 覆盖了主要变体与边界状态。

## 目录结构

```text
lumina/
├── .storybook/            # main.ts / preview.ts / decorators.tsx（主题切换）
├── src/
│   ├── components/        # 一个组件一个目录，文件名 kebab-case
│   │   ├── button/
│   │   │   ├── button.tsx
│   │   │   ├── button.module.css
│   │   │   ├── button.stories.tsx
│   │   │   └── index.tsx
│   │   ├── menu/          # 多文件组件：组件 + hook + 工具函数同目录
│   │   └── segmented/     # 同目录下多个相关组件（Control + Tabs）
│   ├── icons/             # 内联 SVG 图标（组件依赖的最小集合）
│   ├── styles/
│   │   ├── tokens.css     # 设计令牌（亮 / 暗）
│   │   ├── primitives.css # 组件需要、令牌文件里没有的基础变量
│   │   ├── global.css     # 全局重置
│   │   └── index.css      # 样式入口（tokens → primitives → global）
│   ├── intro/             # 文档页（.mdx）
│   └── index.ts           # 公共 API 入口
├── types/                 # 环境类型声明（CSS Modules 等）
└── tsconfig.json          # 类型检查 / 编辑器用（noEmit）
```

## 常用命令

```bash
pnpm dev            # 启动 Storybook（端口 6006）
pnpm docs:build     # 静态构建文档
pnpm check          # typecheck + lint + format:check
pnpm typecheck      # 仅做类型检查
pnpm lint           # ESLint 检查
```

## 新增一个组件

1. 新建 `src/components/<name>/` 目录，包含 `<name>.tsx`、`<name>.module.css`、`<name>.stories.tsx`、`index.tsx`（目录与文件名都用 kebab-case）
2. 组件从 `forwardRef` 导出，props 抽成导出的 `<Name>Props` 接口，用 `clsx` 拼类名
3. 样式只引用 `src/styles` 里的 CSS 变量：优先用 `tokens.css`；缺的基础变量补到 `primitives.css`
4. 在目录的 `index.tsx` 与 `src/index.ts` 中导出组件与其 Props 类型
5. Storybook 会自动收录 `src/**/*.stories.@(ts|tsx)`，并为带 `tags: ['autodocs']` 的组件生成文档页
6. 用到 hooks 或事件处理的组件，文件第一行写 `'use client'`

## 在 Next.js 里使用

要求 **App Router**（Pages Router 下依赖包中的 CSS Modules 会被拒绝）。库本身不做任何编译，所以使用方要让 Next.js 也编译它：

- **pnpm workspace**（推荐）：Turbopack 自动转译，无需配置
- **装成正式依赖**（`pnpm pack` 后安装 / 发布到 registry）：在 `next.config.ts` 里加 `transpilePackages: ['lumina']`

样式需要在 `app/layout.tsx` 引入一次：`import 'lumina/styles.css'`（只要令牌不要 reset 的话用 `lumina/tokens.css`）。React 是 `peerDependencies`，不会重复安装。
