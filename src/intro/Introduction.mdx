<Subtitle>个人使用的 React 组件库</Subtitle>

基于 **React + TypeScript** 的组件库，使用 **CSS Modules** 编写样式，通过 **Storybook** 编写文档。源码不打包，交给使用方（Next.js）编译。

## 技术栈

| 模块   | 方案                                                      |
| ------ | --------------------------------------------------------- |
| 分发   | 直接发布源码，无构建产物（`exports` 指向 `src/index.ts`） |
| 编译   | 使用方负责：Next.js（App Router）转译 TSX 与 CSS Modules  |
| 样式   | CSS Modules + 设计令牌（CSS 变量）                        |
| 类型   | TypeScript（严格模式），类型随源码一起提供                |
| 文档   | Storybook（`@storybook/addon-docs` 自动生成 Docs 页）     |
| 包管理 | pnpm                                                      |

## 目录结构

```text
lumina/
├── .storybook/            # Storybook 配置（main.ts / preview.ts）
├── src/
│   ├── components/        # 组件，一个组件一个目录
│   │   └── <Name>/
│   │       ├── <Name>.tsx
│   │       ├── <Name>.module.css
│   │       ├── <Name>.stories.tsx
│   │       └── index.ts
│   ├── styles/            # 设计令牌、全局样式
│   │   ├── tokens.css
│   │   ├── global.css
│   │   └── index.css
│   ├── intro/             # 文档页（.mdx）
│   └── index.ts           # 公共 API 入口
├── types/                 # 环境类型声明（CSS Modules 等）
└── tsconfig.json          # 类型检查 / 编辑器用（noEmit）
```

## 常用命令

```bash
pnpm dev            # 启动 Storybook（端口 6006）
pnpm docs:build     # 静态构建文档
pnpm check          # typecheck + lint + format:check
pnpm typecheck      # 仅做类型检查
pnpm lint           # ESLint 检查
```

## 新增一个组件

1. 新建 `src/components/<Name>/` 目录，包含 `<Name>.tsx`、`<Name>.module.css`、`<Name>.stories.tsx`、`index.ts`
2. 样式只引用 `src/styles/tokens.css` 中的 CSS 变量
3. 在 `src/index.ts` 中导出组件与其 Props 类型
4. Storybook 会自动收录 `src/**/*.stories.@(ts|tsx)`，并为带 `tags: ['autodocs']` 的组件生成文档页
5. 用到 hooks 或事件处理的组件，文件第一行写 `'use client'`

## 在 Next.js 里使用

要求 **App Router**（Pages Router 下依赖包中的 CSS Modules 会被拒绝）。库本身不做任何编译，所以使用方要让 Next.js 也编译它：

- **pnpm workspace**（推荐）：Turbopack 自动转译，无需配置
- **装成正式依赖**（`pnpm pack` 后安装 / 发布到 registry）：在 `next.config.ts` 里加 `transpilePackages: ['lumina']`

样式需要在 `app/layout.tsx` 引入一次：`import 'lumina/styles.css'`（只要令牌不要 reset 的话用 `lumina/tokens.css`）。React 是 `peerDependencies`，不会重复安装。
