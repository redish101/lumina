基于 **React + TypeScript** 的组件库，使用 **CSS Modules** 编写样式，用 **Vite** 的库模式构建，通过 **Storybook** 编写文档。

## 技术栈

| 模块   | 方案                                                      |
| ------ | --------------------------------------------------------- |
| 构建   | Vite 库模式：ESM 按模块分包 + 每包自带 CSS 导入 + `.d.ts` |
| 分发   | 编译产物 `dist/`，使用方无需再转译，装完即用              |
| 样式   | CSS Modules + 设计令牌（CSS 变量）；样式随组件 tree-shake |
| 类型   | TypeScript（严格模式），声明文件按源码结构输出            |
| 文档   | Storybook（`@storybook/addon-docs` 自动生成 Docs 页）     |
| 包管理 | pnpm                                                      |

## 组件

| 分类 | 组件                                                                           |
| ---- | ------------------------------------------------------------------------------ |
| 表单 | Button、Input、Checkbox、Switch、SegmentedControl、SegmentedTabs、ShortcutKeys |
| 展示 | Pill、Tag、StateDot、TextShimmer、AnimatedRows                                 |
| 浮层 | Menu、Tooltip、Toast                                                           |
| 媒体 | ImagePreview、ImageLightbox、DraggableImage                                    |

每个组件的 Docs 页顶部有行为说明，下面是 props 表格（含中文说明与默认值）；story 覆盖了主要变体与边界状态。

## 目录结构

```text
lumina/
├── .storybook/            # main.ts / preview.ts / decorators.tsx（主题切换）
├── src/
│   ├── components/        # 一个组件一个目录，文件名 kebab-case
│   │   ├── button/
│   │   │   ├── button.tsx
│   │   │   ├── button.module.css
│   │   │   ├── button.stories.tsx
│   │   │   └── index.tsx
│   │   ├── menu/          # 多文件组件：组件 + hook + 工具函数同目录
│   │   └── segmented/     # 同目录下多个相关组件（Control + Tabs）
│   ├── icons/             # 内联 SVG 图标（组件依赖的最小集合）
│   ├── styles/
│   │   ├── tokens.css     # 设计令牌（亮 / 暗、elevation）
│   │   ├── global.css     # 全局重置
│   │   └── index.css      # 样式入口（tokens → global）
│   ├── intro/             # 文档页（.mdx）
│   └── index.ts           # 公共 API 入口
├── dist/                  # 构建产物（不提交）
├── types/                 # 环境类型声明（CSS Modules 等）
├── vite.lib.config.ts     # 库构建配置（Storybook 不吃这份）
├── tsconfig.json          # 类型检查 / 编辑器用（noEmit）
└── tsconfig.build.json    # 生成类型声明用
```

## 常用命令

```bash
pnpm build          # 构建组件库到 dist/（ESM + CSS + 类型声明）
pnpm dev            # 启动 Storybook（端口 6006）
pnpm docs:build     # 静态构建文档
pnpm check          # typecheck + lint + format:check
pnpm typecheck      # 仅做类型检查
pnpm lint           # ESLint 检查
```

## 新增一个组件

1. 新建 `src/components/<name>/` 目录，包含 `<name>.tsx`、`<name>.module.css`、`<name>.stories.tsx`、`index.tsx`（目录与文件名都用 kebab-case）
2. 组件从 `forwardRef` 导出，props 抽成导出的 `<Name>Props` 接口，用 `clsx` 拼类名
3. 样式只引用 `src/styles/tokens.css` 里的 CSS 变量；确实缺的补进 `tokens.css` 的 `:root` 与暗色块
4. 在目录的 `index.tsx` 与 `src/index.ts` 中导出组件与其 Props 类型
5. Storybook 会自动收录 `src/**/*.stories.@(ts|tsx)`，并为带 `tags: ['autodocs']` 的组件生成文档页
6. 用到 hooks / `forwardRef` / 事件处理才在文件第一行写 `'use client'`；纯展示组件不要写，这样能在 Server Component 里直接渲染、不下发 JS（`pnpm check:use-client` 会校验）

## 在应用里使用

```tsx
import { Button } from '@redish101/lumina';

<Button variant="primary">你好</Button>;
```

- 组件样式与设计令牌由这个 import 自动带出，**不需要**单独的 CSS 入口
- 产物已编译，**不需要** `transpilePackages`
- 未 import 的组件不会进入产物（`preserveModules` + 每包独立 CSS）
- 入口不带 `'use client'`：Tag、StateDot、ShortcutKeys 这类纯展示组件在 Server Component 里直接渲染，不进客户端包
- 想要库自带的重置再额外 `import '@redish101/lumina/reset.css'`；只引令牌用 `@redish101/lumina/tokens.css`
- React 是 `peerDependencies`，不会重复安装；包本身没有运行时依赖

Next.js 要求 **App Router**：Pages Router 不允许依赖包内出现 CSS Modules。
